# Plans and worklists

| Folder | Holds |
| --- | --- |
| `todo/` | Open plans and review worklists |
| `blocked/` | Open worklists waiting on something outside the code (still re-checked) |
| `completed/` | Closed plans and worklists. Moved here, never deleted |

Every plan leads with success criteria and names the precedent it follows (see
`CLAUDE.md`, "Working agreement"). Review findings use IDs unique across all
worklists: `W-001`… for code, `S-001`… for security.
